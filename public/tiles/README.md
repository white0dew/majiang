# 牌图命名规范

将真实牌图放在本目录并按以下文件名命名：

- `wan-1.png` ... `wan-9.png`
- `tiao-1.png` ... `tiao-9.png`
- `tong-1.png` ... `tong-9.png`
- `dong.png` `nan.png` `xi.png` `bei.png`
- `zhong.png` `fa.png` `baiban.png`
- `back.png`（牌背）

共 35 张图片（34 张牌面 + 1 张牌背）。

说明：
- 当前项目已提供同名占位图，可直接替换为你的真实素材。
- 建议图片比例接近 `3:4`，例如 `120x160`、`240x320`。
